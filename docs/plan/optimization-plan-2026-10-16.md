## 三、必须先澄清的决策点

以下三项**不是技术问题，而是事实/取向问题**，任何一项没定，对应的方案就无法正确排期。它们都是 `[DECIDE]`，不阻塞其他工作。

### S1：当前 CI 是否为红？（可 30 秒核实）

- **已知事实**：QA 报告实测 `pnpm test:unit` 在 `2026-10-16T04:03Z` 有 1 个失败（`lessons-hygiene` 待复核比例 43.7% > 42% ratchet）。
- **未核实**：该失败是本地环境特有，还是 master 上同样存在。
- **核实方式**：查最近一次 GitHub Actions 运行结论（`gh run list --workflow=ci.yml --limit 5`），或本地重跑 `pnpm test:unit` 复现。
- **影响**：若为红，M14 必须**最先做**——它意味着当前所有「跑通了」的声明都建立在红的基础上；若仅本地态，M14 降为 P2 并说明原因。

### S2：无头链路 vs 油猴链路，谁是主力？

- **已知事实**：`README.md:5.3` 标油猴为「默认」，无头为备选；但工作台顶栏提供对等切换。
- **未知**：实际使用占比（无埋点）。
- **影响**：headless 调度层（`headless-scheduler.ts` / `browser-engine.ts` / `headless-slot-queue.ts`）的补测优先级。
- **若油猴是主力**：M1 从 P0 降为 P1，可释放约 5 人日给 M2（video）。
- **若两者对等或未知**：维持 P0（保守）。
- **无需埋点也能做的判断**：查 `packages/core/src/headless/` 与 `scripts/tampermonkey-session-id.user.js` 的近期 churn 对比——被改得多的那条链路，更可能是主战场。

### S3：video 模块是正式功能还是实验代码？

- **已知事实**：`packages/core/src/video/**` 共 1642 行源码、前端面板 473 行，**零测试覆盖**；`README.md` 与 `AGENTS.md` **均未提及 video**；180 天 churn=11、fix-like=2。
- **未知**：它是否已被用户实际使用、是否计划长期维护。
- **影响**：决定 M2（8 人日）+ M3（4 人日）是否值得投入，合计 12 人日。
- **若为实验代码**：整块降级为 P2，只做 M3（组件最小冒烟），把 8 人日让给 M1/M4。
- **若为正式功能**：维持 P0，且需在 README 补文档说明（当前它「存在但无人知晓」）。
- **低成本判断方式**：`git log --oneline -- packages/core/src/video` 看提交者是否持续在改、`VideoGenerationPanel.vue` 是否有最近 UI 迭代。

### S4：是否计划国际化（出海）？

- **已知事实**：无 `vue-i18n` 依赖；25 个 `.vue` 组件硬编码中文；`market_hints.lang = ["zh"]`。
- **影响**：M12（i18n 词条抽取，5 人日）的优先级。
- **若不出海**：M12 维持 P2，可从路线图中删除。
