# Testing Vue Vitest

## 目标

为 Vue 3 项目补齐有价值、低脆弱的测试。不要为了覆盖率堆测试，优先覆盖核心路径和高风险分支。

## 工作方式

1. 先阅读目标组件、组合式函数、API 封装和已有测试写法。
2. 识别测试层级：工具函数、composable、组件、页面行为。
3. 优先覆盖核心路径，再补异常、权限、空数据和回归场景。
4. mock 外部依赖，但不要 mock 被测逻辑本身。
5. 断言用户可感知结果，少断言实现细节。
6. 跑测试并修正不稳定断言。

## 推荐覆盖

- 表单校验和提交
- 搜索、重置、分页
- 空数据和接口异常
- 弹窗打开、回显、关闭
- 权限按钮显隐
- composable 的状态变化
- 关键事件 emit
